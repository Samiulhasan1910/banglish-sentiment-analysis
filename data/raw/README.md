# Raw data

Place `BDFoodSent-334k.csv` in this folder before running the pipeline.

- **Dataset:** BDFoodSent: A Large-Scale Sentiment-Labeled Restaurant Review Dataset from Bangladesh
- **Authors:** Ehsanur Rahman Rhythm, Md Humaion Kabir Mehedi
- **Version:** Mendeley Data v2 (December 2, 2024)
- **DOI:** [10.17632/532fxhnwbb.2](https://data.mendeley.com/datasets/532fxhnwbb/2)
- **License:** CC BY 4.0

The file (~132 MB, 334,119 reviews) is not tracked in Git because it exceeds GitHub's 100 MB file limit.
